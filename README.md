# Полка игр для Samsung TV

Оболочка приложения для телевизоров Samsung (Tizen): значок «Полки игр» на главном экране телевизора,
внутри открывается личная полка игр (вход по паролю). Пульт работает как пульт: стрелки, ОК, «Назад», каналы ∧/∨ — по рядам.

Установка — через [TizenBrew Installer](https://github.com/reisxd/TizenBrewInstaller): «установить приложение из GitHub» → `Maks-nerd/game-shelf-tv`.
